# api-testing-postman
Учебный проект по тестированию REST API в Postman


## Что тестировалось

- Получение списка пользователей (GET)
- Получение пользователя по ID (GET)
- Обработка несуществующего пользователя (GET 404)
- Создание пользователя (POST)
- Обновление пользователя (PUT)
- Удаление пользователя (DELETE)
- Удаление несуществующего пользователя

## Что выполнено

- Отправка HTTP-запросов
- Проверка HTTP-статусов
- Проверка JSON-ответов
- Проверка структуры и данных ответа
- Позитивное и негативное тестирование
- Автоматизация проверок с помощью Postman Tests
- Использование переменных окружения

## Проверки

В тестах проверяются:

- HTTP status code
- формат ответа
- наличие обязательных полей
- типы данных
- корректность переданных данных
- содержимое ответа

## Инструменты

- Postman
- JavaScript
- REST API
- HTTP
- JSON
- Git / GitHub

## API

Для тестирования использовался публичный API JSONPlaceholder.

## Результат

Создан набор API-запросов с автоматизированными проверками ответов для основных CRUD-операций.
